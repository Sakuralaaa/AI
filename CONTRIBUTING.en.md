# Contributing

[简体中文](CONTRIBUTING.md)

Corrections, clearer explanations, and safe non-programming examples are welcome.

1. Chinese is the content source. Update `docs/zh-CN` first, then synchronize `docs/en`.
2. Keep paths paired and update `resources/translation-status.yml`.
3. For a new external tool, record its source type, upstream link, purpose, risks, and verification date.
4. Do not contribute real credentials, account-sharing instructions, payment workarounds, or geographic-restriction bypasses.
5. Examples must be safe to publish; use synthetic or explicitly authorized data.
6. Run `D:\Anaconda\Anaconda\python.exe scripts/check_bilingual.py` before submitting, or wait for GitHub Actions.

Write like an experienced friend: explain why before the steps, then define how to verify the result. Avoid hype, and never trade technical accuracy for the vehicle metaphor.
