# 00｜上车之前：先完成一次安全体验

[English](../en/00-before-driving.md) · [返回首页](../../README.md)

## 先记住一句话

第一次使用 Agent，不要急着让它“全自动干活”；先让它在一个可恢复的练习目录里只读观察、说明计划，再做一个很小的改动。

## 为什么你会需要它

聊天机器人通常给你答案，Agent则可能读取文件、运行命令并留下真实修改。这很有用，也意味着模糊的要求会变成真实的混乱。正确的第一课不是“最强提示词”，而是理解工作区、权限和验收。

你不需要会编程，但需要能够回答三件事：材料在哪里、想得到什么、怎样判断结果正确。

## 跟着做一次：10分钟只读练习

1. 新建一个名为 `agent-practice` 的目录，复制三份不敏感的练习文档进去；不要使用唯一原件。
2. 在 Codex 中打开这个目录，保留默认沙箱和审批设置。
3. 发送下面的任务：

```text
请只读检查当前目录，不要创建、删除、移动或修改任何文件。
列出文件名、类型和大致用途；指出重复、命名不一致或缺少说明的地方。
最后给出一个整理计划，并明确哪些步骤会修改文件。现在不要执行计划。
```

4. 把 Agent 的文件清单和资源管理器逐项对照。
5. 选择一个低风险动作，例如新建 `inventory.md`，要求它只记录清单，不移动原文件。
6. 打开结果文件，检查内容和编码；不满意就说明具体差异，让它修改新文件。

## 我踩过的坑

- 一开始就说“把这里整理好”，Agent只能猜你的分类规则。
- 在下载目录、论文原始数据或同步盘根目录练习，出错后很难恢复。
- 看到“任务已完成”就关掉窗口，没有打开生成文件。
- 把沙箱关掉来解决所有权限问题，反而扩大了误操作范围。

## 正常结果

- Agent准确列出练习文件，没有改动原文件。
- 它把建议和实际操作分开说明。
- 你能在工作区内找到新建的清单，并知道是谁、为什么创建了它。
- 如果要求超出权限，Agent会请求审批或说明受限，而不是悄悄绕过。

## 验收清单

- [ ] 使用的是副本或合成材料。
- [ ] 第一轮任务明确写了“只读”和“不要修改”。
- [ ] 文件清单与实际目录一致。
- [ ] 修改前看过计划。
- [ ] 亲自打开并检查了结果。
- [ ] 知道如何撤销或删除本次练习产物。

## 到这里，你已经能做什么

你已经完成一次安全的 Agent 循环：提供范围、限制权限、查看计划、允许小步执行并人工验收。后面的文件、表格、PPT和Stata案例都只是这个循环的扩展。
