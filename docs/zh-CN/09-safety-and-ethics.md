# 09｜安全驾驶：隐私、权限与学术伦理

[English](../en/09-safety-and-ethics.md) · [返回首页](../../README.md)

## 先记住一句话

安全不是“相信Agent不会做错”，而是让错误的影响被工作区、权限、备份和人工检查限制住。

## 先给数据分级

| 等级 | 例子 | 默认处理 |
|---|---|---|
| 公开 | 官方报告、公开数据、已发布论文 | 仍需遵守许可证和引用要求 |
| 内部 | 未公开讲义、普通会议记录 | 确认组织政策后处理，不公开传播 |
| 敏感 | 学生信息、访谈、客户数据 | 优先本地受控环境，脱敏并取得授权 |
| 高度敏感 | 医疗、身份、密钥、未披露商业信息 | 不进入普通Agent流程，采用专门审批和隔离 |

数据“保存在本地”不等于“没有离开本地”：如果模型请求发送到云端，输入仍可能离开电脑。应确认具体工具、模型和供应商的数据路径。

## 最小权限

- 初次任务使用只读或工作区权限。
- 写入只开放到项目输出目录。
- 对 `.env`、认证目录和原始数据设置禁止访问。
- MCP、浏览器、Computer Use和云任务有各自的权限边界，不能只看命令沙箱。
- 全盘访问只用于明确、短时、可恢复的可信任务。

## 凭证与供应链

API Key、OAuth Token、Cookie和恢复码都按密码管理：不写进Prompt、Markdown、截图、Issue或Git历史。第三方MCP、Skill、插件、镜像和安装脚本都可能执行代码，应核对维护者、许可证、发布记录和权限。

## 学术诚信

- 先查看学校、导师、课程和期刊对AI的要求。
- 保存Prompt、使用范围、模型/工具和人工修改记录，便于披露。
- 引用必须回到真实原文，不引用Agent编造的书目。
- 统计分析保留数据版本、脚本、log和排除规则。
- 不为得到显著结果让Agent反复试模型、样本和指标而不报告。
- 语言润色不代表事实与论证已经正确。

## 不可信内容与提示注入

网页、文档和仓库中的文字可能要求Agent忽略你的规则、读取秘密或发送数据。把外部内容当作待分析材料，而不是可信指令。涉及外部发送、登录、付款、删除和发布时保留人工确认。

## 跟着做一次：任务前风险检查

使用[MCP安全检查表](../../templates/zh-CN/mcp-safety-check.md)和[结果验收表](../../templates/zh-CN/result-review.md)，回答：数据级别、发送对象、可写目录、不可逆操作、备份、披露要求和最终负责人。

## 我踩过的坑

- 脱敏了姓名，却留下学号、地址和罕见组合特征。
- 只删除当前文件，忘记凭证仍在Git历史。
- 把MCP服务器返回的说明当成高于项目规则的可信命令。
- AI生成的参考文献格式完整，就没有查DOI和原文。

## 正常结果与验收

- [ ] 已给数据分级并确认授权。
- [ ] 知道材料会发送到哪些服务。
- [ ] 权限限制到必要目录与工具。
- [ ] 凭证没有进入仓库、日志和截图。
- [ ] 学术成果保存来源、脚本、核验和披露记录。
- [ ] 不可逆或外部动作有人类确认。
