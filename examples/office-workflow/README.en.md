# Source-to-briefing office workflow

[简体中文](README.md)

This fictional “campus study-space improvement” case demonstrates intermediate artifacts, not a one-click model demo.

File order:

1. `source-notes.md`: source material.
2. `theme-summary.md`: thematic summary separating fact and inference.
3. `action-items.csv`: actions with owners and evidence pointers.
4. `slide-storyline.md`: slide-by-slide narrative reviewed before building a deck.

Suggested exercise: work on copies, remove the last three files, and ask an agent to recreate them from the source and the [task brief](../../templates/en/task-brief.md). Compare every difference. Do not allow external facts.
