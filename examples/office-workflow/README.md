# 资料到汇报：办公工作流

[English](README.en.md)

这是一个完全虚构的“校园学习空间改进”小案例，用来演示中间产物，而不是展示某个模型的一键成品。

文件顺序：

1. `source-notes.md`：原始材料。
2. `theme-summary.md`：区分事实与推断的主题摘要。
3. `action-items.csv`：可以追踪负责人和证据的行动表。
4. `slide-storyline.md`：PPT逐页故事线，真正制作幻灯片前先审它。

建议练习：删除后三个文件的副本，让Agent依据原始材料和[任务简报模板](../../templates/zh-CN/task-brief.md)重新生成，再逐项比较差异。不要要求它补充外部事实。
