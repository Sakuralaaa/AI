# Synthetic Stata-MCP case

[简体中文](README.md)

This directory demonstrates a reproducible workflow in which an agent invokes specialist software through MCP. The data are entirely synthetic: five units, four years, and twenty rows. The sample is far too small for real causal inference.

Files:

- `synthetic_panel.csv`: synthetic panel data.
- `analysis.do`: example script using built-in Stata commands only.
- `verification.en.md`: human verification checklist.

Prepare a valid Stata installation and license, then follow current [MCP-for-Stata](https://github.com/SepineTam/mcp-for-stata) documentation. Confirm Stata starts independently before testing MCP in Codex. Do not substitute personal or restricted data without authorization, environment review, and privacy assessment.
