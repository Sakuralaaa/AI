# 术语表

[English](glossary.en.md) · 最后核验：2026-09-22

| 术语 | 汽车比喻 | 准确解释 |
|---|---|---|
| Agent框架 / Agent harness | 车 | 组织模型、上下文、工具调用、执行循环和用户界面的软件 |
| Model | 油 | 负责理解输入、推理和生成输出的模型；能力、速度和成本不同 |
| Provider | 加油站 | 提供模型访问、身份验证、计费和可用性保障的服务方 |
| Prompt | 目的地与导航要求 | 用户交给Agent的目标、背景、约束和验收条件 |
| Context | 当前地图和随车资料 | 本轮任务可见的对话、文件、说明、工具结果等信息 |
| Token | 油耗计量单位 | 模型处理文本等内容时使用的计量单位；不等同于字数或金额 |
| API Key / OAuth | 油卡或车钥匙 | 访问服务的认证手段，必须按秘密管理 |
| Base URL | 加油站入口 | 客户端向兼容API发送请求的基础地址 |
| CC-Switch | 油路切换面板 | 管理多个Agent客户端的供应商、MCP、Skills和相关配置 |
| CLIProxyAPI（CPA） | 本地中转站 | 将支持的上游接入整理为兼容API的独立社区项目；不是文件格式 |
| MCP | 车载扩展接口 | 连接Agent与外部工具、服务和上下文的协议与集成方式 |
| Skill | 驾驶手册或模式 | 可复用的工作流说明，可附带脚本、模板和参考资料 |
| Plugin | 改装套件 | 可打包Skills、MCP、界面或其他扩展的安装单元；不同产品定义可能不同 |
| Sandbox | 道路护栏 | 限制命令、文件系统或网络访问的执行边界 |
| Approval | 人工放行 | Agent在执行特定操作前向用户请求确认 |
| Failover | 备用路线 | 当前服务失败后按规则尝试其他可用服务 |

汽车比喻用于建立直觉。遇到配置和安全问题时，请以“准确解释”列和原项目文档为准。
