# AGENTS.md example

## Project goal

This directory is used for an auditable source-to-briefing workflow.

## Directory rules

- `input/` contains read-only source material.
- `work/` contains intermediate artifacts.
- `output/` contains final deliverables.

## Working agreements

- Inventory relevant files and explain the plan before editing.
- Preview batch operations and wait for user approval.
- Do not invent sources; mark missing evidence as unverified.
- Use only tools and external sources explicitly allowed by the task.

## Done when

- List files actually created or modified.
- Perform appropriate static checks and human review.
- Report unverified content and remaining risk.
